Projects

Card payments monitoring

Planned · weeks 1 to 9

A card issuer's daily spending view and first line of fraud rules. Synthetic card transactions are generated in Python, loaded through Cloud Storage into partitioned BigQuery tables, and modelled in Dataform into a star schema and rule-based alerts, with assertions at each layer.

  • Python
  • pytest
  • Cloud Storage
  • BigQuery
  • Dataform
  • GitHub Actions

FX trades and positions

Planned · weeks 15 to 20

An FX desk's end-of-day positions and sterling revaluation P&L. Synthetic spot and forward trades with amendments and cancellations are joined to public Bank of England exchange rates, kept as point-in-time history with checks for stale or missing rates.

  • Python
  • Cloud Storage
  • BigQuery
  • Dataform
  • GitHub Actions

Each project links to its folder in this repository once its first pull request is merged. Finished projects include a README, architecture and data model diagrams, Dataform assertions, sample outputs and notes on what would change in production.
